UpperDeck support

For login issues, bugs, reports or account recovery, email upperdecktcg@gmail.com.

Login codes

Request a new six-digit code in the app. Codes expire after ten minutes. Check spam and use the newest email. Never send your code, password or API keys to support.

Changes waiting to sync

Open Profile → Settings → Sync. Your unsent changes stay on your phone. If an item changed on another device, review the saved versions there before choosing which to keep.

Tournament corrections

The first accepted match report finalizes a result. Ask the event host to correct a mistake. Corrections are retained in the event history.

Reporting a problem

Include the app version, the screen and the steps that led to the issue. Screenshots help, but please hide login codes and private notes. Public profiles include Block and Report actions.

UpperDeck is an independent fan project and is not affiliated with Bandai or the One Piece rights holders. Tournament standings in UpperDeck are not a substitute for an organizer’s official records.
