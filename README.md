# UpperDeck for SideStore

Add this source in SideStore (or AltStore):

```
https://raw.githubusercontent.com/okaraah/upperdeck-sidestore/main/source.json
```

SideStore → Sources → + → paste the URL → open UpperDeck → Get.

Requires iOS 26.0 or later. Builds are unsigned; SideStore signs them with your Apple ID. With a free Apple ID the app expires after 7 days unless SideStore refreshes it.
